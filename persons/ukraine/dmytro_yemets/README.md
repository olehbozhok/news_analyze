## Хто це

Прокурор САП; у засіданні ВАКС 18.11.2026 з обрання запобіжного заходу Андрію Осіпову («Карфаген-2») підтримував тримання під вартою і озвучував версію обвинувачення.

## Спорні епізоди

- 18.11.2026 — засідання ВАКС по Осіпову: за переказом Суспільного, Ємець стверджував, що впродовж 2022–2026 років діяла злочинна організація (Осіпов — один із керівників, кол-центри зокрема U420), неправомірна вигода близько 220 тис. дол., збитки близько 42 млн грн; захист оскаржуватиме рішення в апеляції.
