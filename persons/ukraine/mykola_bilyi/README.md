## Питання / НЕПІДТВЕРДЖЕНЕ

1. Зв'язок «кум» з Федоровим — незалежно не підтверджений; «Наші гроші» і РБК подають його як твердження видань. → [01/SC-64](../../../analyses/ukraine/zakhyst_krytychnoi_infrastruktury_2026_11/sources/source_cards_01.md#sc-64)
2. «Укрмедгрупа» фігурує у провадженні Нацполіції щодо 703,22 млн грн оплат НСЗУ — зв'язок Бєлого з цим провадженням у темі не розглядався. → [01/SC-64](../../../analyses/ukraine/zakhyst_krytychnoi_infrastruktury_2026_11/sources/source_cards_01.md#sc-64)
3. Період депутатства у Запорізькій міськраді — у джерелах теми не названий.
