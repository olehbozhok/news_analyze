# Валерій Залужний

**Актуальна станом на:** 14.11.2026

## Хто це

Генерал; на 24.02.2022 — головнокомандувач ЗСУ (з 07.2021); пізніше — посол у Великій Британії (посадові дати після 02.2024 у цій темі не звірені).

## Спорні епізоди

- «Дело Залужного»: у вузьких політичних колах справу ДБР про окупацію юга називали «делом Залужного»; за даними Бі-бі-сі, слідчі ходили «на бесіду», але процесуального статусу у Залужного немає. Статус: назва справи в колах — факт; звинувачення — НЕПІДТВЕРДЖЕНЕ. → [01/SC-04](../../../analyses/ukraine/minni_zahorodzhennia_2021_2022/sources/source_cards_01.md#sc-04)
- Наєв у інтерв'ю 10.02.2025 зараховує підготовку до вторгнення до «ініціативи, самостійних рішень головнокомандувача ЗСУ генерала Залужного, мене...» — це власна позиція Наєва. Статус: позиція сторони. → [01/SC-09](../../../analyses/ukraine/minni_zahorodzhennia_2021_2022/sources/source_cards_01.md#sc-09)

## Питання / НЕПІДТВЕРДЖЕНЕ

1. Кого саме «притягувати до відповідальності» за підготовку півдня — Залужний публічно не давав відповіді; його позиція в справі не розкрита (запити Бі-бі-сі в ДБР/СБУ — відмова).
2. Дата призначення ГК ЗСУ указом (27.07.2021) — не звірено в темі.
