# Антон Кравчук

**Актуальна станом на:** 20.11.2026
**Покриття:** картка
**Джерело даних:** [«Карфаген»: хабарі, кол-центри і наркотрафік](../../../analyses/ukraine/karfahen_2026_11/01_karfahen.md) — картки [01/SC-37](../../../analyses/ukraine/karfahen_2026_11/sources/source_cards_01.md#sc-37), [01/SC-43](../../../analyses/ukraine/karfahen_2026_11/sources/source_cards_01.md#sc-43), [01/SC-165](../../../analyses/ukraine/karfahen_2026_11/sources/source_cards_01.md#sc-165)

## Хто це

Полковник СБУ (за ZN.UA), начальник Головного управління внутрішньої безпеки СБУ (на момент операції «Карфаген-2», листопад 2026); 04.11.2026 у нього провели обшуки. Не плутати з колишнім генпрокурором Русланом Кравченком ([Руслан Кравченко](../ruslan_kravchenko/README.md)) — інша особа.

## Спорні епізоди

- 04.11.2026 — обшуки НАБУ/САП (справа «Карфаген») у Кравчука як начальника ГУ внутрішньої безпеки СБУ (разом з обшуками в Дуки і Ковальчука). Статус: доведено як медійне повідомлення з джерел (ZN.UA, DW за джерелами УП); обшук не є підозрою, процесуальний статус публічно не підтверджений. → [01/SC-37](../../../analyses/ukraine/karfahen_2026_11/sources/source_cards_01.md#sc-37), [01/SC-43](../../../analyses/ukraine/karfahen_2026_11/sources/source_cards_01.md#sc-43)
- 16–18.11.2026 — за твердженням анонімного джерела УП («не під запис»), матеріали НСРД з грифом «цілком таємно», які Кравченко публікує з 16.11, Кравченку «міг передати» Кравчук. Статус: версія анонімного джерела без документальної опори, не факт. → [01/SC-165](../../../analyses/ukraine/karfahen_2026_11/sources/source_cards_01.md#sc-165)

## Питання / НЕПІДТВЕРДЖЕНЕ

1. Ім'я «Кравчук» у переліку відсторонених 18.11.2026 (теза Дуки на ТСК, імена за машинним ASR [01/SC-136]) — ймовірно той самий Кравчук (зіставлення caveat [01/SC-165]), але через ASR-запис і без офіційного підтвердження відсторонення ідентифікація не встановлена.
2. Публічних підозр Кравчуку немає; офіційної заяви СБУ щодо обшуків або його кадрового стану в карткованих джерелах теми немає. → [01/SC-37](../../../analyses/ukraine/karfahen_2026_11/sources/source_cards_01.md#sc-37)
