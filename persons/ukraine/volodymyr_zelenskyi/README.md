# Володимир Зеленський

**Актуальна станом на:** 11.11.2026
**Покриття:** картка
**Джерело даних:** [«Мідас»](../../../analyses/ukraine/midas_2025_2026/README.md) (документ [01_midas.md](../../../analyses/ukraine/midas_2025_2026/01_midas.md), source cards `sources/source_cards_01.md`)

## Хто це

Президент України (з 20.05.2019). У справі «Мідас» фігурує як той, хто звільнив Ірину Мудру з посади заступниці керівника ОП 19.08.2026 [01/SC-41], і як особа джерельної версії УП про доручення Буданову операції із пошуку та легалізації коштів на заставу Галущенка — твердження анонімних співрозмовників, не факт слідства [01/SC-31][01/SC-32].

## Питання / НЕПІДТВЕРДЖЕНЕ

1. Чи існує будь-яке офіційне підтвердження або спростування версії УП про доручення Зеленського — станом на 11.11.2026 не знайдено.
2. У повному переказі клопотання ВАКС (hromadske, 26.08.2026) Зеленський не згадується [01/SC-33].
