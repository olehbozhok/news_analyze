## Спорні епізоди

- За Кротевичем, Прокопенко — один із трьох свідків планування оборони Маріуполя (разом із Кротевичем і Андрієм Харківим). Статус: позиція Кротевича. → [02/SC-09](../../../analyses/ukraine/minni_zahorodzhennia_2021_2022/sources/source_cards_02.md#sc-09)
- Оцінка наслідків непідриву мостів Чонгару: «практично без боїв, маршем» (УП, 06.07.2023) — цитата з теми 01. Статус: позиція учасника. → [01/SC-22](../../../analyses/ukraine/minni_zahorodzhennia_2021_2022/sources/source_cards_01.md#sc-22)
