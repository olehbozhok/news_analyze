## Хто це

Співробітник Нацполіції (за медіа — заступник начальника відділу карного розшуку ГУНП Київщини); фігурант «Карфагену» — медійне ототожнення з псевдонімом «Консультант»; 06.11.2026 ВАКС обрав тримання під вартою без застави (до 02.01.2027 за переказами).

## Спорні епізоди

- 06.11.2026 — запобіжний захід у «Карфагені»: тримання під вартою без застави (до 02.01.2027 за переказами). Статус: доведено як судове рішення за публічними переказами (прізвище — за медіа, офіційні пресрелізи називають псевдонім «Консультант»). → [01/SC-47](../../../analyses/ukraine/karfahen_2026_11/sources/source_cards_01.md#sc-47)
- Червень–липень 2026 (версія обвинувачення в суді 18.11) — за даними прокурора, допомагав нападникам, які побили Якименка біля фітнес-клініки в центрі Києва, «уникнути затримання». Статус: твердження обвинувачення, не встановлені судом факти. → [01/SC-122](../../../analyses/ukraine/karfahen_2026_11/sources/source_cards_01.md#sc-122), [01/SC-129](../../../analyses/ukraine/karfahen_2026_11/sources/source_cards_01.md#sc-129)

1. Ототожнення «Консультант» = Олександр Дем'янчук — медійне, офіційно не підтверджене. → [01/SC-10](../../../analyses/ukraine/karfahen_2026_11/sources/source_cards_01.md#sc-10)
