# Єгор Буркін («Мексиканець»; за санкційним записом — Левченко Єгор Васильович)

## Хто це

Єгор Буркін («Мексиканець») — за версією Нацполіції, лідер угруповання «Хімпром»; у міжнародному розшуку з 2019 року (СБУ — з 2016); 13.11.2026 дав перше велике публічне інтерв'ю на YouTube-каналі Василя Тимошенка. Судом лідерство не встановлене.

## Спорні епізоди

- 13.11.2026 — публічне інтерв'ю на YouTube-каналі Василя Тимошенка (2:29:36, без відео): підтвердив, що на записах «Карфагена» це він і що хабарі платилися; назвав суми «криші» (21 тис. дол./міс. за центр, по 7 тис. трьом органам) і оцінки масштабу (1500 центрів, 350–370 млн дол./рік), які розходяться з обліком слідства (52 центри). Статус: факт інтерв'ю — доведено; зміст тверджень — позиція джерела. → [03/SC-01](../../../analyses/ukraine/karfahen_2026_11/sources/source_cards_03.md#sc-01), [03/SC-02](../../../analyses/ukraine/karfahen_2026_11/sources/source_cards_03.md#sc-02), [03/SC-04](../../../analyses/ukraine/karfahen_2026_11/sources/source_cards_03.md#sc-04)

Статус: позиція джерела без незалежного підтвердження; Татаров і Кравченко у справі «Карфаген» не фігурують; реакцій сторін станом на 14.11.2026 не знайдено. → [03/SC-03](../../../analyses/ukraine/karfahen_2026_11/sources/source_cards_03.md#sc-03), [03/SC-05](../../../analyses/ukraine/karfahen_2026_11/sources/source_cards_03.md#sc-05), [03/SC-07](../../../analyses/ukraine/karfahen_2026_11/sources/source_cards_03.md#sc-07), [03/SC-14](../../../analyses/ukraine/karfahen_2026_11/sources/source_cards_03.md#sc-14)

## Питання / НЕПІДТВЕРЖДЕНЕ

1. Чи звертався Буркін до НАБУ/САП фактично, і чи підтвердять це бюро/САП.
2. Чи з'являться процесуальні наслідки його тверджень про Татарова і Кравченка у справах «Карфагена».
3. «Червоне повідомлення Інтерпола» (слова інтерв'юера у вступі) — не перевірено; у джерелах теми зафіксований лише «міжнародний розшук» НПУ [02/SC-01].
4. Розбіжність імені «Олег/Єгор Левченко» у справі Тищенка не пояснена ([03/SC-12]).
