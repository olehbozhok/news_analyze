# Григорій Омельченко

**Актуальна станом на:** 14.11.2026
**Покриття:** картка
**Джерело даних:** [minni_zahorodzhennia_2021_2022](../../../analyses/ukraine/minni_zahorodzhennia_2021_2022/README.md)

## Хто це

Генерал-лейтенант СБУ у відставці, народний депутат України 2-6 скликань, кандидат юридичних наук; у полеміці про Чонгар — один із головних поіменних звинувачувачів «ЗЕ-влади».

## Спорні епізоди

- Звинувачення «ЗЕ-влади» (блог на Цензор.НЕТ, 18.07.2023): влада «призначила "стрілочника"» — Івана Сестриватовського — який «взяв на себе відповідальність за НЕ ПІДРИВ чонгарських мостів, що призвело до здачі півдня України». Статус: позиція звинувачувача. → [01/SC-12](../../../analyses/ukraine/minni_zahorodzhennia_2021_2022/sources/source_cards_01.md#sc-12)
- У тому ж блозі звинувачує Зеленського і Єрмака в держзраді через зрив операції «Авеню» (2020) — суміжна лінія, верифікована в інших темах не була. Статус: позиція звинувачувача, НЕПІДТВЕРДЖЕНЕ в цій темі.

## Питання / НЕПІДТВЕРДЖЕНЕ

1. Блог не містить первинних доказів зв'язку непідриву мостів із рішеннями ОП; текст — декларації колишнього слідчого.
2. Політична ангажованість (опонент ЗЕ-влади) — враховувати при оцінці.
