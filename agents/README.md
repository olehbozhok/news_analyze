# Ролі агентів

Канонічні файли ролей для циклу з [`AGENTS.md`, розділ 3](../AGENTS.md). Промпт агенту не переказує флоу ролі, а посилається на файл ролі й додає лише специфіку задачі ([`AGENTS.md`, розділ 2.1](../AGENTS.md)).

Файли — звичайний markdown без frontmatter. Вони однаково працюють у Claude Code і opencode, тому назви інструментів у них узагальнені: `chrome_*`, WebFetch, WebSearch (префікси залежать від середовища).

## Індекс

| Роль | Файл | Крок циклу (AGENTS.md, 3) | Працює з вебом |
|---|---|---|---|
| Researcher | [`researcher.md`](researcher.md) | 2. Research | так |
| Writer | [`writer.md`](writer.md) | 3. Draft; 6. Final check (пошук новин) | на кроці пошуку новин перед здачею |
| Red team | [`red_team.md`](red_team.md) | adversarial check (AGENTS.md, 6.3) | так |
| Verifier | [`verifier.md`](verifier.md) | 4. Verification | так |
| Editor | [`editor.md`](editor.md) | 5. Corrections; 6. Final check | коли додає нові джерела і на кроці пошуку новин |

Writer і Verifier — різні агенти ([`AGENTS.md`, розділ 2](../AGENTS.md)). Verifier бажано запускати з чистим контекстом.

## Як викликати агента

```
Роль: agents/<роль>.md — прочитай і виконуй.
Сьогодні <дата>. Тема: analyses/<країна>/<тема>/.
Задача: <документ або питання>.
Вхід: <файли>. Вихід: <шляхи>.
Веб: використовуй браузер Chrome (chrome_*), якщо доступний; якщо інструменти
не завантажені — завантаж їх через пошук інструментів. WebFetch/WebSearch —
запасний варіант. Для кожного URL фіксуй інструмент; якщо Chrome недоступний — зазнач це.
```

## Особливості сайтів

Прийоми для сайтів, на яких агенти застрягали. Інструмент у журналі URL фіксувати так, як вказано в дужках.

| Сайт | Проблема | Як читати |
|---|---|---|
| `reyestr.court.gov.ua/Review/<id>` (ЄДРСР) | текст рішення — у вкладеному `iframe#divframe` з власним скролом; скрол сторінки нічого не дає | повний текст уже в DOM: `document.getElementById('txtdepository').value` (HTML, прибрати теги) або `document.getElementById('divframe').contentDocument.body.innerText` через `chrome_javascript` («Chrome (JS, txtdepository)»); запасний варіант — `curl` сторінки й вміст `#txtdepository` («curl») |
| `t.me/<канал>/<id>` (Telegram-канали відомств) | навігація Chrome на пост може не відкривати текст | `t.me/<канал>/<id>?embed=1` через `curl` або Chrome («curl, embed») |
| `zakon.rada.gov.ua` | WebFetch повертає 403 | Chrome або `curl` з браузерним User-Agent |

Як шукати судові рішення — [`AGENTS.md`, розділ 5, п. 23](../AGENTS.md).

## Що головний агент додає автоматично

Без нагадування користувача, у кожен промпт:

- шлях до файлу ролі;
- сьогоднішню дату;
- шляхи до теми, вхідних файлів і очікуваних артефактів;
- для ролей, що працюють із вебом, — рядок «Веб» із шаблону вище (Chrome як основний інструмент, завантаження `chrome_*`, WebFetch/WebSearch як запасний варіант, інструмент для кожного URL);
- для Verifier — що це окремий агент, який документ не писав.

Флоу ролі, чеклісти й заборони в промпт не копіюються: вони у файлі ролі та в [`AGENTS.md`](../AGENTS.md).
