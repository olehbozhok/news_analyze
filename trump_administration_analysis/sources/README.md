## Результати перевірки URL

- **62** URL повернули 2xx/3xx (доступні).
- **30** — 403/401/429 (антибот-захист, не обов'язково биті).
- **5** — 406/402 (блокування за типом клієнта).
- **0** — 404 Not Found серед перевірених.

Повний лог: `url_check_raw.txt`.

## Важливі застереження

1. Три сирі файли охоплюють лише частину тем (імміграція, здоров'я, верховенство права). Економіка, зовнішня політика й екологія досліджувалися окремими агентами, чиї повні виводи не збережені у файлах, але ключові твердження перевірені безпосередньо (див. `09_verifikatsiia_dzherel.md`).
2. HTTP 403/406 не означає, що сторінка не існує: це антибот-захист (Cloudflare, Akamai тощо). Такі джерела перевірялися через браузер або пошуковий сніпет.
3. Сирі виводи агентів можуть містити помилки. Вони збережені **для прозорості**, а не як остаточна істина. Остаточні твердження — у файлах звіту, де вказано статус перевірки.
