# Verification notes (тема: мінні загородження 2021-2022)

## Повторювані класи помилок, знайдені при перевірці 14.11.2026

1. **Переказ позиції посадовця як факт з іншим предметом (SC-06).** Данілов у Бі-бі-сі говорить про захоплену російську мапу наступу; дослідник переніс у claim «мапу мінних полів мали видати» — предмет твердження підмінено при стисненні.
   Пропозиція правила (тема): для позицій посадовців цитувати пряму мову з джерела повністю, без заміни об'єкта («мапа» без уточнення, якої саме).
2. **«Підтверджень немає» без перечитування уже використаних джерел (залізничний міст).** УП-реконструкція (вже цитувалась за 4 картками) містила «міни вибухнули, але руйнувань не було» — негативне твердження написано за NV, а не за повним корпусом використаних джерел.
   Пропозиція правила (тема): перед «інших підтверджень немає» перечитувати всі вже відкриті повні тексти (чекліст п. 22).
3. **Дати, взятої з переказу, немає в джерелі (Генштаб «04.2022»).** Дату заяви відомства додано до тексту без опори.
   Пропозиція правила (тема): якщо джерело цитує заяву без дати — у документі писати «дата заяви в джерелі не вказана», а не вгадувати період.
4. **Картка персони відстає від хронології (Наєв «командир ТГ з 02.2024»).** Дата кар'єрної події перенесена з неправильно прочитаного рядка джерела (звільнення 02.2024 ≠ нова посада 02.2025).
   Пропозиція правила (тема): у хронології посад кожен рядок мати з окремої дати події в джерелі, не зі згадки «зараз на посаді».
