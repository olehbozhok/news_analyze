## Scope

Коротко: хто публічно звинувачував кого в розмінуванні, незамінуванні чи зриві інженерного
обладнання територій, які РФ використала для наступу в повномасштабному вторгненні
(кримські перешийки/Чонгар — ядро; північний кордон — другорядна лінія); з розширенням
14.11.2026 — усі напрямки й території з початку вторгнення, включно з Донбасом 2014-2021
(документ 02). Кожне звинувачення — як позиція звинувачувача, не факт.

Див. [scope_contract.md](scope_contract.md).
