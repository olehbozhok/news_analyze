# Реєстр проблемних справ цивільного захисту, 2022–2026

**Станом на:** 10.11.2026
**Горизонт:** 24.02.2022 — 10.11.2026
**Статус:** ЧЕРНЕТКА (верифікація Verifier ще не проведена)

## Scope

Реєстр публічно відомих кримінальних проваджень, підозр, обшуків і вироків щодо розкрадання коштів на цивільний захист: захист енергетичної та критичної інфраструктури, укриття і сховища, пункти незламності й генератори, відновлення житла та комунальної інфраструктури, гуманітарна допомога. Призначення — робочий реєстр для вибору справ, які теми розглядатимуть детальніше. Це не аналіз причинності і не верифікована стаття.

Критерій входження: провадження / підозра / обшук / вирок / офіційне реагування або резонансний скандал із джерелом у надійних ЗМІ (URL) або первинним джерелом відомства.

Поза темою: оборонні закупівлі, зброя, паливо для ЗСУ, митниця і податкова поза зв'язком із цивільним захистом, воєнні злочини РФ, колабораціонізм. Справа захисту енергооб'єктів Київщини (№ 01) детально розібрана в суміжній темі [zakhyst_krytychnoi_infrastruktury_2026_11](../zakhyst_krytychnoi_infrastruktury_2026_11/README.md) — тут лише один рядок на епізод.
