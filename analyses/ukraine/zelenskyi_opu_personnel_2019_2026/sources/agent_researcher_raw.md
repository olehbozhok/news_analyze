# Сирі нотатки research (реєстр людей ОП)

> Дата: 09.11.2026. Нотатки не редагуються після здачі.
> Виконавець: головний агент сесії (докладніше нижче).

## Відхилення від регламенту (зафіксувати для Verifier)

Регламент передбачає окремого Researcher-агента. Три запуски субагента впали на внутрішній помилці середовища: 500 "utf-8 codec can't encode character '\ud835' (surrogates not allowed)" — спецсимволи поза базовою Unicode-площиною, що потрапляли в контекст агента з вебконтенту, ламали запит до API; відновлення падало на тій самій позиції (контекст «отруєний»). Останній субагент встиг створити SC-01 і початок журналу URL (успадковано), після чого впав остаточно.

Тому research виконано головним агентом сесії з конвеєром без потрапляння сирого вебконтенту в контекст моделі: curl → python3 -I (санація: видалення всіх символів поза BMP) → файл → Read. Ролі Writer і Verifier залишаються окремими агентами (головне правило розділу 2 не порушується). Промпт субагента зберігся: sources/agent_prompt_research.md.

## Інструменти

- chrome_* у середовищі відсутні. Основні: browsermcp (браузер Chrome користувача), curl + python3 -I санація, WebSearch. WebFetch — не працює для op.gov.ua (DNS) і не використовувався для zakon (curl надійніший).
- op.gov.ua: домен не резолвиться (ERR_NAME_NOT_RESOLVED) у curl, WebFetch і Chrome. Сторінка «Керівництво Офісу» — через редирект president.gov.ua/administration/office-management. Це зафіксовано в SC-03 і журналі URL.
- zakon.rada.gov.ua: періодично тротлінгить curl (403/404 без UA/після серії запитів); паузи 1.5–3 с вирішують; браузер працює завжди.
- Пошук указів: SPA-пошук zakon («в назві» + «в тексті») через browsermcp; списки результатів — через .txt-експорт списку (uuid) через curl.

3. Вікіпедія (2 статті) — тільки roadmap: списки керівників за президентів; використано для перевірки повноти (збігається з указами).
