# AGENTS.md — специфіка теми: люди Офісу Президента за Зеленського

Діє разом із кореневим [`AGENTS.md`](../../../AGENTS.md). Тут лише специфіка теми; загальні правила (ролі, статуси джерел, заборони) не послаблюються. Що входить у реєстр — у [`scope_contract.md`](scope_contract.md).

## Структура теми

| Елемент | Призначення |
|---|---|
| `01_liudy_opu.md` | Реєстр усіх осіб ОП за категоріями; кожен рядок — посилання на папку персони |
| `persons/<imia_prizvyshche>/` | Папка аналізу однієї особи (транслітерація латиницею, snake_case, без кирилиці, пробілів і великих літер) |
| `persons/README.md` | Індекс персон з посиланнями й статусами персональних аналізів |
| `sources/` | Source cards, research brief, сирі нотатки для реєстру |

## Правила `persons/`

1. Кожна особа з реєстру `01_liudy_opu.md` має папку `persons/<imia_prizvyshche>/` з `README.md` — карткою персони: посади в ОП з періодами, посилання на картки реєстру, питання для подальшого аналізу, статус.
2. Статус персонального аналізу — `ЧЕРНЕТКА` (тільки рядок реєстру) → `НА ПЕРЕВІРЦІ` → `ГОТОВО` (розділ 10 кореневого AGENTS.md); фіксується в `persons/README.md`.
3. Посилання з реєстру на персону — `[Ім'я Прізвище](persons/<name>/README.md)`; посилання на папку завжди веде на її README.
4. Картки реєстру лежать у `sources/source_cards_01.md`; у `01_liudy_opu.md` посилання — `[SC-NN]` (обгортає `scripts/sc_links.py --fix`). `sc_links.py` обробляє лише `NN_*.md` у корені теми, тому в README персони на картки реєстру посилатися прямим markdown-посиланням: `[SC-01](../../sources/source_cards_01.md#sc-01)`.
5. Персональні документи аналізу — `persons/<name>/NN_<tema>.md`, їхні картки — `persons/<name>/sources/source_cards_NN.md`. Скрипт їх не обробляє: усередині папки персони посилання на картки писати явними markdown-посиланнями.
6. Ім'я папки персони унікальне й стабільне; за збігу імен додати по батькові або розрізнювальний суфікс.
7. Одна особа — одна папка, незалежно від кількості посад в ОП: усі посади фіксуються в README персони й у рядку реєстру.
8. Позаштатні радники 2019–2020 не отримують персональних папок (scope contract, «Не входить»); якщо окрема особа з них стає предметом аналізу — за прямим рішенням користувача.
