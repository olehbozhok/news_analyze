## Принципи

- Кожне ключове твердження має картку `[SC-NN]`; у документі посилання клікабельні після `python3 scripts/sc_links.py --fix`.
- Первинні джерела — офіційні сайти НАБУ, ОГП, НПУ, СБУ, судові повідомлення.
- Медійні джерела — лише з посиланням на конкретну публікацію і дату.
- Сирі нотатки не цитуються у фінальному тексті.
- `rozsliduvach.info` заблокований DDoS-Guard; його твердження не використані як єдине джерело.
